# nonebot_plugin_whofindme

记录群聊中的 `@` 消息，并在需要时查询「谁 @ 了我」。

## 功能

- 仅在**群聊**中生效。
- 某用户 `@` 另一用户时，记录该消息，包含：
  - 群号
  - 发送者 QQ
  - 发送者昵称（群名片优先，回退到昵称）
  - 被 `@` 者 QQ
  - 文本内容（如有）
  - 图片（如有，记录图片 URL）
  - 时间戳
  - 被引用（回复）消息的概要：序列化其段结构（图片 → `[图片]`、视频 → `[视频]`、文本 → 内容、其他 → `[其他]`），并在查询结果中展示「谁引用了谁的消息」。
- 自动**忽略机器人自身的 QQ**（无论是机器人发出的消息，还是有人 `@` 机器人，均不记录）。
- 查询指令：`谁@我` / `谁艾特我` / `谁找我`，只返回：
  - **当前群**
  - **最近 24 小时**内
  - `@` 了指令发送者本人 的消息
- 查询结果以**合并转发（一条转发消息）**形式返回，避免多条消息刷屏；单条转发内最多展示**最近 50 条**，超出时会在转发首条注明总数。
- 超过 **7 天**的记录自动删除（后台每小时清理一次）。

## 安装

1. 安装依赖（主要是异步 SQLite 驱动）：

   ```bash
   pip install aiosqlite
   ```

2. 将整个 `nonebot_plugin_whofindme` 文件夹放入你的 NoneBot 项目的 `plugins/` 目录，
   或将其所在目录加入 `plugin_dirs`，NoneBot 会自动加载。

## 配置

可在项目根目录的 `.env`、环境变量或 `config.py` 中覆盖以下配置项：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `plugin_whofindme_bot_qq` | 留空（自动检测） | 机器人自身 QQ，**默认无需配置**，自动取连接 self_id；如需强制指定（如多 bot）可填数字 |
| `plugin_whofindme_data_dir` | `./data/whofindme` | SQLite 数据目录，**每个群一个独立 .db 文件**（`<data_dir>/<group_id>.db`），不同群数据物理隔离；目录自动创建 |
| `plugin_whofindme_data_path` _(旧版，兼容)_ | _(无)_ | 旧版单文件路径配置。**仅当用户显式自定义过非默认值**时才沿用其所在目录；默认情况下不再"取父目录"摊平到 `data/`，而是落在 `data/whofindme/` 专项目录 |
| `plugin_whofindme_keep_days` | `7` | 记录保留天数，超过自动删除 |
| `plugin_whofindme_query_hours` | `24` | 查询回溯的小时数 |
| `plugin_whofindme_max_results` | `50` | 合并转发最多展示最近多少条记录 |
| `plugin_whofindme_use_forward` | `true` | 是否使用合并转发回复。部分 NapCat + NTQQ 组合发送带图合并转发会报 `retcode=1200` / 超时，此时设为 `false`，回退为单条纯文本消息（图片以链接呈现），更稳定 |

机器人 QQ 默认**自动检测**，正常情况下无需任何配置即可使用。示例 `.env`（仅当你需要覆盖默认值时才写）：

```env
# plugin_whofindme_bot_qq=你的QQ  # 通常不用写，插件会自动识别
# plugin_whofindme_data_dir=./data/whofindme  # 数据目录（默认），每群一个 .db 文件
plugin_whofindme_keep_days=7
plugin_whofindme_query_hours=24
# plugin_whofindme_use_forward=true  # 若合并转发报错，改为 false
```

## 使用

在群里发送以下任意一条即可触发查询（不要求先 @ 机器人）：

```
谁@我
谁艾特我
谁找我
```

返回示例（以一条**合并转发**消息呈现，点开查看明细）：

```
┌─ 转发消息：最近 24 小时内，本群共有 2 条 @ 你的消息 ─┐
│ [查询汇总]                                          │
│  [08-10 14:30] 张三(10001) @了你                    │
│      内容：帮我看下这个 bug                          │
│      <图片>                                          │
│  [08-10 09:12] 李四(10002) @了你                    │
│      内容：中午一起吃饭吗                            │
└─────────────────────────────────────────────────────┘
```

> 备注：合并转发依赖 OneBot 实现的 `send_group_forward_msg` 能力（go-cqhttp / NapCat / Lagrange 等均支持）。
> 若运行环境不支持，插件会自动回退为单条普通消息，功能不受影响。

## 说明

- 若一条消息同时 `@` 了多个人，会为每个人各记一条，保证各自查询准确。
- `@全体` 不会被记录（只记录明确 @ 某个用户）。
- 查询仅在消息所属群内生效，不会跨群。
